# Personal Portfolio Website

A responsive personal portfolio website developed using HTML, CSS and JavaScript.

## About

This project is a personal portfolio website created to showcase my academic background, technical skills, projects, certifications, achievements and resume.

The website is designed with a clean, modern and responsive interface that works on desktop, tablet and mobile devices.

## Features

- Responsive design
- Dark mode
- Project filtering
- Resume download
- Contact form
- Mobile navigation
- Project showcase
- Social media links
- Smooth scrolling
- Interactive user interface

## Technologies

- HTML5
- CSS3
- JavaScript
- Font Awesome
- Google Fonts

## Website Sections

- Home
- About

- Projects
- Certifications
- Achievements
- Resume
- Contact
